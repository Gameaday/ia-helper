# Play Release Notes ("What's New")

> Google caps release notes at **500 characters** per language. Keep each entry under the cap — the drafts below already are.

## v1.7.0 — Play debut (November 2026)

```
Welcome to IA Helper on Google Play! 📚

• Search 35M+ Internet Archive items with filters for media type, year, collection, and language
• Batch downloads with file rules, auto-retry, and pause/resume
• Offline library with a built-in metadata viewer
• No ads, no tracking, no subscriptions — ever

Built for researchers, archivists, and data hoarders. Feedback and feature requests: GitHub issues.
```

*(~430 characters — fits the 500 limit.)*

## Future updates — template

```
What's new in {version}:

• {headline feature — one line, user benefit}
• {second change}
• Fixes: {one or two user-visible fixes}

Questions or ideas? Reach us via GitHub issues — links in Settings → About.
```

## Rules for these notes

1. Lead with what the *user* gets, not what changed in the code.
2. No "various bug fixes and improvements" without at least one concrete fix named.
3. When the Pro tier launches, mention founding pricing once in the release note — then let the listing carry it.
